# セルの描画

ヘッダは `renderHeader`、セルは `renderBody`、フッタは `renderFooter` で描画します。
いずれも戻り値の React 要素がそのまま中身になります。

<Source language="tsx" code={`
  const [rows, setRows] = React.useState<Row[]>(...)

  // TypeScript の型推論のためのヘルパー関数。利用は任意。
  // getValuesForRender の戻り値の型は通常は any だが col.leaf 経由で定義するときちんと型推論されるようになる。
  const col = createColumnHelper<Row>()

  // フッタのレンダリング用
  const rowsRef = React.useRef(rows)
  rowsRef.current = rows

  const columns = React.useMemo(() => [
    col.leaf({
      columnId: "quantity",

      // ヘッダの描画。
      // 高さは1行分で固定されており、縦幅が自由に伸縮したりはしない。
      renderHeader: () => <span>数量</span>,

      // ボディセルの描画。
      // getValuesForRender でセルの再レンダリング判定、兼、ボディセルの描画に使う値の抽出を行い、
      // renderBody では getValuesForRender が返した値を使ってレンダリングする。
      getValuesForRender: row => [row.quantity],
      renderBody: ({ deps: [quantity] }) => <span>{quantity}</span>,

      // フッタセルの描画。
      // 配列を渡すと上から1段ずつ描画される。段が足りない列のフッタは空のセルになる。
      renderFooter: [
        () => <span>{sum(rowsRef.current, row => row.quantity)}</span>,
        () => <span>{average(rowsRef.current, row => row.quantity)}</span>,
      ],
    }),
  ], [rowsRef])

  <EditableGrid
    columns={columns}
  />
`} />

### セルが描画し直される条件

パフォーマンスの最適化のため、再レンダリングの条件は厳密に管理されています。

| 変化 | 描画し直される範囲 |
| --- | --- |
| `subscribe` で通知する | `getValuesForRender` の戻り値が変わったセルと、フッタ全体 |
| `getLatestRowObject` / `isReadOnly` / `showCheckBox` / `getRowClassName` の参照が変わる | 同上 |
| `rowKeys` の要素の値か並び順が変わる | 同上に加えて、並びが変わった位置から下の行のセル |
| `columns` の参照が変わる | ヘッダ・セル・フッタのすべて |
| それ以外の props の参照が変わる（`onRowsChange` など） | なし |

行と列は仮想化されているため、この表のヘッダ・セル・フッタは描画範囲内に含まれるものだけを指します。
画面外の行や列はそもそも描画されていないため、行数や列数が多くても描画し直される量は画面に映る範囲までです。
仮想化については <Link to="その他/パフォーマンス">パフォーマンス</Link> を参照してください。

グリッドは行データの配列を受け取らず、`getLatestRowObject` で必要なときに値を取りに行きます。
そのため、セルの値が変わったこと自体はグリッドには伝わりません。
`subscribe` の通知や関数の参照の変化をきっかけに、描画中のセルがそれぞれ `getValuesForRender` を呼び直して前回の戻り値と要素ごとに比べ、戻り値が変わったセルだけを描画し直します。

セルの描画に使う値は、すべて `getValuesForRender` の戻り値に含めてください。
`renderBody` が行オブジェクトを受け取らないのはこのためです。
含め忘れた値が変わっても、セルの表示は古いままになります。

列定義の中で参照しているグリッドの外側の値（state や props）はセルの値ではないため、この比較には乗りません。
外側の値の変化がセルに伝わる経路は、`columns` の参照が変わることだけです。
そのため列定義は `useMemo` で包み、列定義の中で参照している外側の値をすべて依存配列に含めてください。
含め忘れると、外側の値を変えてもセルの表示が変わりません。
逆に `useMemo` で包まないと、グリッドを含むコンポーネントが再レンダリングされるたびに `columns` の参照が変わるため、1セルを編集しただけで描画中の全セルが描画し直されます。

<Source language="tsx" code={`
  const [includeTax, setIncludeTax] = React.useState(false)

  const columns = React.useMemo(() => [
    col.leaf({
      columnId: "amount",
      getValuesForRender: row => [calcAmount(row, includeTax)],
      renderBody: ({ deps: [amount] }) => <span>{amount}</span>,
      ...
    }),
  ], [includeTax]) // 列定義の中で参照している外側の値
`} />

上のデモの「金額」列は、グリッドの外側のチェックボックスの state `includeTax` に依存しています。
ヘッダと金額の両方が切り替わるのは、`columns` の参照が変わって両方が描画し直されているからです。

## ボタンやチェックボックスを置く場合の注意点

セル内のボタンなどでは、`mousedown` イベントの `stopPropagation` を呼んでください。
呼ばない場合、ボタンを押したときにグリッドのセル選択の処理も動きます。

<Source language="tsx" code={`
  renderBody: ({ rowKey }) => (
    <button
      type="button"
      onMouseDown={e => e.stopPropagation()}
      onClick={() => addQuantity(rowKey)}
    >
      ＋1
    </button>
  ),
`} />
