# 読み取り専用

セルを読み取り専用にすると、そのセルは背景色が変わり、編集・ペースト・Delete キーによるクリアができなくなります。

以下の例では、上部のチェックボックスでグリッド全体を、「行ロック」列のボタンで行単位の読み取り専用を切り替えられます。
「単価」「金額」列は列単位で、「割引率」列は数量に応じてセル単位で読み取り専用になっています。

## 指定方法

読み取り専用は「グリッド全体」「行単位」「列単位」「セル単位」で指定できます。
**あるセルがこれらの指定のうちいずれか1つにでも該当すれば** 、そのセルは読み取り専用になります。

### グリッド全体

<Source language="tsx" code={`
  <EditableGrid2
    isReadOnly // グリッド全体を読み取り専用にする
    {...}
  />
`} />

### 行単位

<Source language="tsx" code={`
  <EditableGrid2
    isReadOnly={(row, rowIndex) => row.status === "確定"} // 確定済みの行は編集させない
    {...}
  />
`} />

### 列単位

<Source language="tsx" code={`
  <EditableGrid2
    columns={[{
      columnId: "unitPrice",
      isReadOnly: true, // 列全体
      ...
    }]}
  />
`} />

### セル単位

<Source language="tsx" code={`
  <EditableGrid2
    columns={[{
      columnId: "discountRate",
      isReadOnly: (row, rowIndex) => (row.quantity ?? 0) < 10, // 数量10以上の行でのみ入力可
      ...
    }]}
  />
`} />

## セルエディタと関係ない入力コンポーネント

グリッドが制御するのは、セルエディタによる編集とペースト・Delete だけです。

`renderBody` で描画したボタンやチェックボックスはセルエディタと関係ないコントロールのため、
引数 `isReadOnly` （グリッド全体・行単位・列単位をすべて考慮した判定結果）を使って明示的に無効化してください。上記デモの「至急」列がこの例です。

<Source language="tsx" code={`
  renderBody: ({ row, isReadOnly }) => (
    <input
      type="checkbox"
      checked={row.urgent}
      disabled={isReadOnly} // チェックボックスを操作できなくする
      ...
    />
  ),
`} />

## 読み取り専用に設定していないのにセル編集できない場合

その列にエディタ関連の定義（ `editor` / `getValueForEditor` / `setValueFromEditor` ）が定義されていない可能性があります。

「ユーザーが入力する項目だが、今は入力させない」ことを見た目で伝えたい場合は `isReadOnly` を、
ボタン列のようにそもそも値を持たない列ではエディタ関連の定義を省略する、という使い分けを想定しています。

詳細は <Link to="編集/セルエディタ">セルエディタ</Link> のページを参照してください。

## 見た目について

グリッドが読み取り専用セルに対して行う見た目の変更は、**セル自身の背景色を塗らなくなる**ことだけです。
通常のセルは白（`striped` 指定時は縞模様）で塗られますが、読み取り専用セルは塗られず、
グリッドの地の色（既定ではグレー）がそのまま見える状態になります。

文字色を薄くする、鍵アイコンを出すといったそれ以外の見た目には、グリッドは一切関与しません。
セルの中身のレイアウトはすべて `renderBody` で決めるものなので、読み取り専用かどうかで表示を変えたい場合は、
`renderBody` の引数 `isReadOnly` を見て利用側で切り替えてください。
