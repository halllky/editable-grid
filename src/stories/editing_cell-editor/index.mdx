# セルエディタ

セルをダブルクリックしたりキー入力したりしたときに表示される、
実際に値を入力するコンポーネントは利用側で実装します。

エディタを標準で提供していないのは、必要な入力コントロール
（テキスト、選択肢、日付、数値、ボタン付き入力…）や、
キー入力時の仕様（例えば Alt + Enter で改行するか Shift + Enter で改行するか等）が
アプリケーションごとによって大きく異なり、汎用的な実装を1つに決め打ちできないためです。

セルエディタが満たすべき契約は型として公開されており、
それさえ満たせばどのような外観・仕様のエディタでも組み込めます。

以下のエディタでセルにカーソルを合わせ、F2または任意の文字入力をしてみてください。

## 組み込み方

EditableGrid2 のプロパティ `onRowsChange` を定義します。

続いて、各列の定義に以下3項目を定義します。
`editor`（列定義かグリッド全体のどちらか）と `textToCell` が無い列は、編集不可の列として扱われます。

* `editor` : エディタのUIコンポーネント
* `cellToText` : 編集開始時にセルからエディタへ渡す初期値（文字列）を返す処理。クリップボードへのコピー時の処理も兼務している。
* `textToCell` : 編集終了時にエディタの文字列を反映した**新しい行オブジェクトを返す**処理。クリップボードからのペースト時の処理も兼務している。

`textToCell` は引数の行を書き換えず、新しい行オブジェクトを返します。
グリッドはそれを `onRowsChange` に渡すので、実際のデータへの反映は `onRowsChange` の中で行います。
文字列を解釈できない場合は `undefined` を返すと、そのセルへの書き込みはスキップされます。

<Source language="tsx" code={`
  <EditableGrid2
    rowKeys={rows.map(r => r.id)}
    getLatestRowObject={index => rows[index]}

    // グリッドの操作（編集確定・貼り付け・Delete）による変更の反映先
    onRowsChange={updates => setRows(prev => {
      const next = [...prev]
      for (const { rowIndex, row } of updates) next[rowIndex] = row
      return next
    })}

    columns={[
      {
        columnId: "name",
        renderHeader: () => <span>商品名</span>,
        getValuesForRender: row => [row.name],
        renderBody: ({ deps: [name] }) => <span>{name}</span>,

        // エディタに必要な3項目
        editor: MyTextEditor,
        cellToText: row => row.name ?? '',
        textToCell: (row, text) => ({ ...row, name: text }),
      },
    ]}
  />
`} />

## クイック編集

セルを選択した状態で文字キーを押すと、`F2` やダブルクリックを経由せずにいきなり編集が始まります。
このとき、セルの元の値は破棄され、押した文字が入力された状態から編集が始まります。

日本語入力（IME）がオンの状態でも、**最初に打った1文字目が取りこぼされることなく**、そのまま変換候補として入力されます。
これはグリッドにフォーカスがある間、非編集時も含めて、見えない状態のセルエディタに常にフォーカスが当たっているためです。
キー入力が最初からセルエディタに届くため、1文字目から IME の変換が効きます。

編集の確定（`Enter`）・キャンセル（`Escape`）といった編集中のキー操作は、グリッドではなくセルエディタ側で実装します。

なお、読み取り専用のセルや、エディタ関連の定義（`editor` / `textToCell`）が無い列では、
文字キーや `F2` を押しても編集は始まりません。選択は通常どおりできます。

## セルエディタ基本形

前述の editer に渡すコンポーネントの例。
必ず EditableGridCellEditor 型にすること。
props は EditableGrid2 側から渡される各種情報、
ref はこのコンポーネントから EditableGrid2 に情報を返すのに使う。

<Source language="tsx" code={`
  export const SimpleTextCellEditor: EditableGridCellEditor = React.forwardRef((props, ref) => {

    // 編集中の値はエディタコンポーネント自身が保持する
    const [value, setValue] = React.useState<string>('')

    const textareaRef = React.useRef<HTMLTextAreaElement>(null)

    // props に入っている変数の使い方は当該型定義の JsDoc を参照
    const { style, isEditing, requestCommit, requestCancel } = props

    // ref が実装すべき処理は当該型定義の JsDoc を参照
    React.useImperativeHandle(ref, () => ({
      blur: () => textareaRef.current?.blur(),
      getCurrentValue: () => textareaRef.current?.value ?? '',
      setValueAndSelectAll: (value: string) => {
        setValue(value)
        textareaRef.current?.select()
      },
      getDomElement: () => textareaRef.current,
    }), [textareaRef])

    // エディタ上で発生したイベントの処理。
    // ここをどう実装するかに決まりはないので自由にカスタマイズしてよい。
    const handleKeyDown: React.KeyboardEventHandler<HTMLTextAreaElement> = e => {
      if (isEditing) {
        // 編集確定
        if (e.key === 'Enter' || e.key === 'Tab') {
          if (e.shiftKey) return;
          requestCommit(value)
          e.preventDefault()
          return
        }
        // 編集キャンセル
        if (e.key === 'Escape') {
          requestCancel()
          e.preventDefault()
          return
        }
      }
    }
    const handleChange: React.ChangeEventHandler<HTMLTextAreaElement> = e => {
      setValue(e.target.value)
    }

    // エディタの外観は自由に決めることができる。
    // ただし、エディタの位置などは EditableGrid2 側で計算しているため、
    // その計算結果が入っている props.style をエディタ側のルートDOM要素に設定すること。
    return (
      <textarea
        ref={textareaRef}
        value={value ?? ''}
        onChange={handleChange}
        onKeyDown={handleKeyDown}
        className="px-1 py-px text-sm resize-none field-sizing-content outline-none border border-black bg-white"
        style={style}
      />
    )
  })
`} />
