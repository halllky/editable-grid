# 最小限の実装

行データを React の state で持つ場合の、表示して編集できるようにするまでの最小限の実装です。
React Hook Form で行データを管理する場合は <Link to="その他/react-hook-form との統合">react-hook-form との統合</Link> を参照してください。

## すべてのグリッドで必須

`EditableGrid2` を使う場合は以下の属性を指定する必要があります。

* `rowKeys`
  * 行を一意に識別する文字列の配列。この配列の長さがグリッドの行数になります。
  * 行の追加・削除・並べ替えをしても同じ行に同じ値が付いたままになるもの（行のIDなど）を渡してください。
    グリッドは行のチェック状態などを `rowKeys` の値ごとに保持しているため、行インデックスを渡すと、行を削除したときなどにそれらが別の行へずれます。
  * 同じ値を2回以上含めてはいけません。
  * まだIDの無い新規行には、行を作るときに `crypto.randomUUID()` などで一時的なキーを割り当ててください。
* `getLatestRowObject`
  * 行インデックスと rowKey を受け取り、その行の値を返す関数。
  * 表示・編集・コピーに使う値はすべてこの関数から取得されます。
* `columns`
  * 列定義。多くのプロパティがあるので各種説明ページを参照してください。

## 編集可能なグリッドの場合は必須

ユーザーからの編集を受け付けるグリッドの場合は以下の設定が必要です。

* 入力方法の定義。列単位で指定が必要です。
  * <Link to="編集/セルエディタ">セルエディタ</Link>
  * <Link to="編集/コピー＆ペースト">コピー＆ペースト</Link>
* `onRowsChange`
  * 上記入力が確定したときに、その変更をグリッド呼び出し側の state などに反映する処理。
  * クリップボードからの貼り付けの場合、1セルごとではなく変更範囲全体がまとめて渡ります。
