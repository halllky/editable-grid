# データが無いときの表示

行が1件も無いとき、グリッドは既定ではボディに何も表示しません。
メッセージなどを表示したい場合は `whenNoData` に表示内容を指定してください。

<Source language="tsx" code={`
  <EditableGrid
    whenNoData={<span>商品が登録されていません</span>}
  />
`} />
