# はじめに

`@halllky/editable-grid` は、Excel のようにセルを選択・編集・コピー＆ペーストできる React のグリッドコンポーネント `EditableGrid` を提供します。

## インストール

npm レジストリからインストールします。

<Source language="bash" code={`
  npm install @halllky/editable-grid
`} />

以下は peerDependencies のため、利用側のプロジェクトにインストールされている必要があります。

| パッケージ | バージョン |
| --- | --- |
| `react` | ^19 |
| `@tanstack/react-table` | ^9.2 |
| `@tanstack/react-virtual` | ^3.14 |

## 読み込み

<Source language="tsx" code={`
  import { EditableGrid } from "@halllky/editable-grid"
`} />

スタイルはパッケージに同梱されているため、CSS を別途読み込む必要はありません。
