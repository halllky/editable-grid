# コピー＆ペースト

コピー＆ペーストは列定義に以下の属性を指定することで有効になります。
（セル編集を有効にするためのプロパティと同じもの）

* `getValueForEditor`
  * その列のセルからクリップボードへのコピー処理を定義します。
  * 未指定の場合、その列のセルからのコピーは空文字になります。
* `setValueFromEditor`
  * クリップボードからそのセルへのペースト処理を定義します。
  * 未指定の場合はその列でペーストしても何も起きなくなります。

クリップボードとの間ではTSV（タブ区切りテキスト）でやり取りするため、
Excelやスプレッドシートソフトとの間でもそのまま貼り付け合うことができます。

以下の例では、グリッドをクリックしてフォーカスした状態で、範囲選択 → `Ctrl + C` / `Ctrl + V` が使えます。
また、範囲選択して Delete キーを押すと、読み取り専用セルを除いて空になります。

グリッド自体はクリップボードとの間で文字列をそのまま受け渡すだけで、型変換・妥当性検証は一切行いません。`setValueFromEditor` には、
文字列との変換ロジックは各項目の仕様に合わせて自由に定義することができます。
キーボード入力やIMEを経由しない任意の文字列（他アプリからの貼り付けを含む）が渡ってくる前提で、
防御的に実装する必要がある点に注意してください。

## 対応している操作

グリッドにフォーカスが当たっている状態で、以下のキー操作に対応しています。

* `Ctrl + C`（コピー）: 選択範囲のセルの値をタブ区切りでクリップボードへ書き込む
* `Ctrl + V`（ペースト）: クリップボードの内容を選択範囲へ書き込む
* `Delete`: 選択範囲のセルの値を空文字にする（ペーストにおける「空文字を貼り付けた」場合と同じ経路で処理される）

**切り取り（`Ctrl + X`）には対応していません。** セルエディタでの編集中は、
これらのキー操作はグリッド側では処理されず、ブラウザ標準のテキストコピペとして
セルエディタ（`<textarea>` 等）に委ねられます。

## 貼り付け範囲の決まり方

貼り付け先の範囲は、ペースト時点の選択状態によって決まります。

* **1セルだけを選択している場合**：貼り付ける内容のサイズに合わせて選択範囲が自動的に拡張され、
  貼り付け後はその拡張後の範囲が選択された状態になります。
  （例：2行2列のデータをコピーし、1セルを選択してペーストすると、貼り付け後は2行2列が選択される）
* **複数セルの範囲を選択している場合**：選択範囲は広がらず、貼り付ける内容が範囲内に
  繰り返し敷き詰められます（内部的には行・列とも剰余で折り返して埋めています）。
  1セルだけコピーして広い範囲に貼り付けると、その値で範囲全体を埋められます。

どちらの場合も、**グリッドの外へははみ出しません。** 行数・列数を超えた分のデータは
そのまま破棄され、**ペーストによって行が新しく追加されることはありません。**
行を増やしたい場合は、あらかじめ利用側で行を追加してからペーストしてください。

```
1セル選択時：クリップボードのサイズ（2行2列）に選択範囲が拡張される
  選択前              貼り付け後
  [■][ ][ ]           [■][■][ ]
  [ ][ ][ ]      →    [■][■][ ]
  [ ][ ][ ]           [ ][ ][ ]

範囲選択時：クリップボードの内容（1行2列）が選択範囲（2行4列）に敷き詰められる
  選択範囲             貼り付け後（A,Bが繰り返し敷き詰められる）
  [■][■][■][■]        [A][B][A][B]
  [■][■][■][■]   →    [A][B][A][B]
```

## 読み取り専用セルへのペースト

読み取り専用のセルは、ペースト時に**その1セルだけがスキップ**されます。
選択範囲の一部に読み取り専用のセルが含まれていてもペースト処理全体が
キャンセルされることはなく、書き込み可能なセルにだけ値が反映されます。
`Delete` による範囲クリアでも同様に、読み取り専用セルだけが変更されずに残ります。

読み取り専用かどうかは、以下のいずれかに該当するかで判定されます。

* グリッド全体の `isReadOnly` が `true`、または行を受け取って `true` を返す関数である
* 列定義の `isReadOnly` が `true`、または行を受け取って `true` を返す関数である

なお、**コピーは読み取り専用のセルに対しても可能**です（`getValueForEditor` さえ
定義されていればよい）。上記デモの「金額」列は `isReadOnly: true` かつ
`setValueFromEditor` 未定義の計算列で、値をコピーすることはできますが、
どんな内容をペーストしても変化しません。

## TSVの仕様

クリップボードとのやり取りには、以下の仕様のTSV（タブ区切りテキスト）を使用します。

* セルの区切りはタブ文字、行の区切りは **CRLF**（Excelへの貼り付けを想定した改行コード）
* セルの値に `"`（ダブルクォート）または改行を含む場合は、そのセル全体を `"` で囲み、
  内側の `"` は `""` に二重化してエスケープする
* 読み込み時はまず `CRLF` を `LF` に正規化してからパースするため、改行コードが
  混在していても問題なく処理できる

この仕様はExcelがクリップボードにコピーする形式と互換なので、上記デモの「備考」列のように
セル内改行を含む値であっても、Excelとの間でそのまま相互にコピペできます。
