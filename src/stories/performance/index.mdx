# パフォーマンス

EditableGrid2 は TanStack Virtual による仮想化を利用しデータ数が多いテーブルの処理高速化を図っています。

以下は **1万行 × 45列（45万セル）** のグリッドです。

* 12ヶ月分の月別列（計画・実績・差異）がグループ列として横方向に並びます。
* セルを編集すると、**同じ行の他の列**（差異・年間計画・年間実績・年間計画金額）へ値が波及します。
* さらに構成比・累計構成比は全行の年間計画の合計を分母に持つため、どこか1セルを編集すると**すべての行**の値が変わります。
  （構成比は1万行のうちの1セルぶんの影響なので動きがごくわずかです。他の行への波及を目で確かめるには累計構成比を見てください。）
* 上部のボタンから、**グリッドの外側**のトリガーでグリッド内の値をまとめて書き換えられます。
* 行の追加と、行頭チェックボックスによる行削除ができます。
