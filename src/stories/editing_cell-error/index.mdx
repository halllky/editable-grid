# セル単位のエラー表示

セル単位のエラー表示のための専用の仕組みはありません。

エラー情報を state などに保持しておき、 `renderBody` でそれを受け取って表示すれば可能です。
エラー情報は以下いずれかの方法で受け取れます。

* `getValuesForRender` でセルの値だけでなくエラー情報も返すようにする（推奨）
* `renderBody` 内部でセルの値を受け取るReactフックを使う

zod などのスキーマ検証ライブラリを使う場合は <Link to="その他/zod との統合">zod との統合</Link> を参照してください。

## renderBody でエラーを表示する（getValuesForRender経由）

セルは `getValuesForRender` の戻り値が変わったときに描画し直されます。
エラーメッセージをこの配列に含めれば、そのままレンダリングに使えます。

<Source language="tsx" code={`
  col.leaf({
    columnId: "name",
    getValuesForRender: (row) => [row.name, getCellError(row, "name")], // getCellError の実装内容は自由
    renderBody: ({ deps: [name, error] }) => <CellText error={error}>{name}</CellText>,
    ...
  })
`} />

なお `getValuesForRender` は描画中のセルの数だけ呼ばれます。
エラーの一覧を毎回線形探索すると行数×列数のコストがかかるため、
上記デモのように「行のキー → 列ID → メッセージ」の形に索引を作っておいてください。

## renderBody でエラーを表示する（Reactフック経由）

`renderBody` はセルごとに独立したコンポーネントとして描画されるため、内部でフックを呼び出せます。
エラーの購読をセル単位で行いたい場合はこの性質を使えます。

<Source language="tsx" code={`
  renderBody: ({ deps: [name], rowKey }) => <NameCell name={name} rowKey={rowKey} />,

  // ...

  function NameCell({ name, rowKey }: { name?: string, rowKey: string }) {
    const error = useCellError(rowKey, "name") // 自分のセルのエラーだけを購読する
    return <CellText error={error}>{name}</CellText>
  }
`} />

ただし、表示中のセルの数だけ購読が張られること、
フックのルール通り呼び出し順が毎回同じでなければならないことに注意してください。
`getValuesForRender` の deps で足りる場合はそちらの方が単純です。
